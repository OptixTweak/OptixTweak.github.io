OptixTweak

FAQ

1. Was ist OptixTweak?

OptixTweak ist eine Demo‑Site für UI/Asset Packs.

2. Wie lade ich ein Produkt herunter?

Nachdem Kauf (simuliert) erscheint der Download‑Button in deinem Dashboard.

3. Welche Dateiformate werden genutzt?

SVG für Icons, WebP für Rasterbilder.

4. Sind Preise in Euro?

Ja, Demo‑Preise sind in EUR.

5. Welche Lizenzarten gibt es?

Demo unterstützt einfache Lizenz Keys (Client‑seitig gespeichert).

6. Wie funktioniert die Registrierung?

Client‑seitiger Demo‑Flow (Phase 4) speichert Accounts in LocalStorage.

7. Wie sicher sind Passwörter?

Demo nutzt Web Crypto‑Hashing. Für Produktion serverseitig ersetzen.

8. Unterstützt ihr Rückerstattungen?

Dies ist eine Demo: kein Zahlungs‑Backend implementiert.

9. Kann ich Webhooks konfigurieren?

Ja, Admin UI bietet Platzhalter für Webhooks (Phase 6/8).

10. Gibt es Discord Integration?

Discord OAuth placeholders werden bereitgestellt (Phase 8).

11. Wie optimiere ich Bilder?

Siehe style‑guide für CLI Befehle (svgo, cwebp).

12. Welche Browser werden unterstützt?

Moderne Chromium, Firefox, Safari (aktuelle Versionen).

13. Wie teste ich Lighthouse?

Lokales Lighthouse oder Lighthouse CI; Ziel Mobile ≥70 Desktop ≥85.

14. Werden Cookies verwendet?

Demo speichert Sessions in LocalStorage (Simulation).

15. Kann ich das Repository klonen?

Ja — Anleitungen in README werden ergänzt.

16. Wie kann ich Produkte hinzufügen?

Admin‑Panel (Phase 6) bietet UI zum Erstellen von Produkten.

17. Gibt es Barrierefreiheitstests?

Phase 9 enthält axe‑core Checks; Ziel AA.

18. Wie sind die Systemanforderungen?

Die Produktseite enthält Beispielanforderungen pro Produkt.

19. Funktioniert die Site offline?

Keine Offline‑Cache Implementierung in der Demo.

20. Wie kontaktiere ich Support?

Kontakt Hinweise im Impressum/Datenschutz Seiten.
